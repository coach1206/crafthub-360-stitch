# Rewards / Passport Terms (Documentation)

Draft terms (documentation only, not a new schema in this pass — reuses existing Rewards/Passport tables from earlier phases): no cash value unless separately approved, nontransferable between accounts, subject to expiration only if explicitly configured (none currently configured), venue-specific limitations may apply, fraud/abuse triggers revocation, correction process exists via the data-rights correction request type, program modification/termination rights reserved, disputes routed through the existing support-case system (Package 5).

**COUNSEL-REVIEW FLAG**: if Golden Box awards or Passport point accumulation could be construed as having cash-equivalent value or resembling a sweepstakes/contest mechanic, this requires dedicated legal review before launch — flagged explicitly in `counsel-review-items.md`. This package does not assert the program is not a regulated promotion; that determination is left to counsel.
