## Batch 22 Alternates — How to Activate

All batch-22 alternates are on disk. To activate one:

1. Update the JSX page file's `src` prop to the batch-22 path
2. Update the matching constant in `src/constants/smokecraftAssets.js`

Constants for all batch-22 alternates are collected in `BATCH22_ALTERNATES` in smokecraftAssets.js.
