## What This Module Does

The SmokeCraft Experience Module provides:

- A canonical module manifest registered in the NOVEE OS module registry
- A route contract for all 17 SmokeCraft journey steps
- A service contract for ordering, pairing, menus, and management sync
- Adapters for POS360, E.A.T., and Passport Connections (placeholder, honest not_connected)
- Hook definitions for journey events
- Permission contracts for customer, staff, manager, and admin roles
- Journey contract that enforces the 8-visit / 24-session structure

## Customer Self-Order Flow

1. Customer enters SmokeCraft journey at `/smokecraft/request-purchase`
2. Customer selects items from venue menu (if connected) or demo items
3. Order is created with `orderMode: 'customer_self_order'`
4. Order status becomes `requested`
5. If POS360 is connected: order is sent via `pos360Adapter.sendOrder()`
6. If POS360 is not connected: order stays `requested` with `syncStatus: 'not_connected'`

**POS Honesty Rule:** The system never claims an order was sent to POS unless `pos360Adapter.isConnected()` returns `true`.

---

## Staff-Assisted Order Flow

1. Staff receives order request from customer (via SmokeCraft journey or direct)
2. Staff order is created with `orderMode: 'staff_assisted_order'`
3. Order status becomes `sent_to_staff`
4. Staff accepts: order becomes `accepted_by_staff`
5. Staff sends to POS: adapter call is made; if not connected, returns `not_connected`

## Pairing

Pairing recommendations are generated by `smokecraftPairingService.js`.

When the pairing engine is not connected, all recommendations return:
```
recommendationStatus: "demo_only"
source: "local_fallback"
aiBacked: false
posBacked: false
venueMenuBacked: false
```

No pairing result claims AI-backed or POS-backed status unless an adapter confirms connection.

## Journey Rules

- **Flavor Memory** must remain between Second Third and Final Third
- **Scorecard** routes upstream to **Passport Stamp**
- **Passport Stamp** cannot be earned early
- **Connections** cannot be unlocked early
- **Visit 8** is protected
- The 8-visit / 24-session structure cannot be compressed or bypassed
- No one-session shortcut is allowed
- Flavor Memory cannot be removed from the journey
