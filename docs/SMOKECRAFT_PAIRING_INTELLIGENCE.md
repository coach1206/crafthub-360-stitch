## Customer Preference Intelligence

**File:** `server/services/smokecraft/smokecraftPreferenceIntelligenceService.js`

Builds a customer taste profile from up to 8 signal sources:

| Signal | Source |
|---|---|
| SmokeCraft Identity | Identity step in journey |
| Humidor Match | Humidor Match step |
| Mentor Selection | Mentor selection step |
| Flavor Memory | Flavor Memory journey step (required) |
| First / Second / Final Third Notes | Phase notes from journey |
| Scorecard | Scorecard ratings |
| Order Selections | Past order items |
| Explicit Likes / Dislikes | Customer explicit input |

Output shape:

```
tasteProfileStatus: "partial" | "established"
confidenceScore: 0–1
preferredStrength, preferredBody
dominantFlavorNotes, secondaryFlavorNotes
avoidFlavorNotes
recommendedWrapperTypes, recommendedOrigins
drinkAffinity, foodAffinity
mentorInfluence
sessionPhaseInfluence
sourceSignals
```

`tasteProfileStatus: "partial"` is returned when `confidenceScore < 0.5`. Confidence is never faked.

## Pairing Scoring Engine

**File:** `server/services/smokecraft/smokecraftPairingScoringService.js`

Calculates structured pairing scores with honest scoring logic.

| Scoring Type | Description |
|---|---|
| Cigar to drink | Flavor affinity + strength-drink match |
| Cigar to food | Flavor affinity + avoid-conflict check |
| Cigar to venue menu item | Pairing tags + flavor affinity |
| Profile to menu item | Taste profile + pairing tags |

Score range: `0–100` (never returns artificial 100 — capped at 98 by logic).
Confidence range: `0–1`.

Each recommendation includes `reasonCodes`, `matchedFlavorNotes`, `conflictingFlavorNotes`, `strengthFit`, `bodyFit`, `mentorFit`, `menuFit`, `phaseFit`.

Allergy/avoidance signals from customer profile always block recommendations — never overridden.

## Menu Recommendation Service

**File:** `server/services/smokecraft/smokecraftMenuRecommendationService.js`

- Scores each venue menu item against cigar profile and taste profile
- Excludes unavailable items
- Marks `staffRequired` and `customerOrderAllowed` honestly
- Carries `pairingRecommendationId` for order payload inclusion
- Returns `venueMenuBacked: false` and `menuSource: "local_fallback"` when no live menu is connected

When venue menu is live-connected (future):
```
venueMenuBacked: true
menuSource: "pos360" | "eat-system" | configured-source
```

## Mentor Recommendation Influence

**File:** `server/services/smokecraft/smokecraftMentorRecommendationService.js`

Supported mentor styles:

| Style | Description |
|---|---|
| `classic_traditionalist` | Classic pairings, formal tone, low risk |
| `flavor_explorer` | Adventurous, curious tone, high risk tolerance |
| `luxury_curator` | Premium pairings, refined tone |
| `beginner_guide` | Mild strength, approachable, welcoming tone |
| `bold_strength_coach` | Full strength, direct tone, adventurous |
| `pairing_sommelier` | Educational, balanced, wine-forward |

**Important:** Mentor influence affects explanation and scoring only. It never overrides customer `avoidFlavorNotes` or `allergyNotes`.

## Flavor Memory

**File:** `server/services/smokecraft/smokecraftFlavorMemoryService.js`

Flavor Memory is a **required** SmokeCraft journey step. It is not removable.

Captured signals:

```
flavorNotes, aromaNotes, burnNotes, drawNotes, retrohaleNotes
likedNotes, dislikedNotes, surpriseNotes
strengthPerception, bodyPerception, finishLength
memoryTags
```

Flavor Memory directly feeds `smokecraftPreferenceIntelligenceService.js` as a preference signal.

## Provider Abstraction

**File:** `server/services/smokecraft/smokecraftPairingProviderService.js`

When no provider is configured:

```
providerConnected: false
aiBacked: false
recommendationStatus: "local_intelligence"
message: "No live AI pairing provider is connected. Recommendation generated by local SmokeCraft intelligence rules."
```

To add a live provider, configure these environment variables **on the server only**:

```
SMOKECRAFT_PAIRING_PROVIDER=provider-name
SMOKECRAFT_PAIRING_ENDPOINT=https://...
SMOKECRAFT_PAIRING_API_KEY=...
```

Do not expose API keys to the frontend. Do not hardcode keys in source code.

## Pairing Audit Trail

**File:** `server/services/smokecraft/smokecraftPairingAuditService.js`

Every recommendation generation creates an audit entry.

Audit events:

| Event | Description |
|---|---|
| `smokeCraft.pairing.profileUpdated` | Customer preference profile updated |
| `smokeCraft.pairing.recommendationGenerated` | Recommendation generated |
| `smokeCraft.pairing.menuRecommendationGenerated` | Menu recommendation generated |
| `smokeCraft.pairing.flavorMemoryCaptured` | Flavor Memory recorded |
| `smokeCraft.pairing.localFallbackUsed` | Local intelligence used (no provider) |
| `smokeCraft.pairing.providerUnavailable` | Provider was attempted but unavailable |

Audit entries do not store secrets or expose private personal data.

## Ordering Connection

Recommended menu items carry `pairingRecommendationId` in the order payload.

`smokecraftMenuRecommendationService.buildOrderPairingPayload()` produces the `pairingRecommendations` array for inclusion in a SmokeCraft order.

POS payload mapping preserves `recommendationId` when available.

When POS360 is not connected, recommendation data is preserved in the SmokeCraft order record only — not sent to POS.
