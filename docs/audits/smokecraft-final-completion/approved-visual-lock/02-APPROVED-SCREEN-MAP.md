# Approved Screen Map — SmokeCraft 360 Visual Lock

Single authoritative map of every production-active SmokeCraft screen: screen ID,
route, canonical component, approved asset key, exact approved asset path, active
asset version, and production status. Generated by cross-referencing
`src/App.jsx` (routes), `src/constants/smokecraftScreenManifest.js` +
`src/constants/smokecraftComponentRegistry.js` (canonical component per screenId),
and `src/constants/smokecraftAssets.js` (`SC_ASSETS`, the single approved asset
registry — every value is cache-busted once via `versionedAssetUrl`, active
version tag `?v=69e419f`).
