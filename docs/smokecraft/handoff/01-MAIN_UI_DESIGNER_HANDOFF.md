the current integration branch and its existing proof artifacts.

## What SmokeCraft 360 is

A guided, gamified cigar-tasting journey for venue guests: enroll → pick an
identity/venue → walk a 27-session curriculum spine (grouped into 6 phases)
covering cigar selection, preparation, three tasting thirds, and reflection →
get an AI summary, pairing recommendations, and a passport stamp → land on
rewards/XP and a recommended next journey. Around that spine sit ~10
supporting modules (Golden Box competition system, mentor selection, seed &
soil education, request/purchase, connections, management sync, etc.) and a
further layer of supplemental/peripheral pages (venue commerce/cart/checkout,
compliance, leaderboard, account, and others) — see doc 03 for the full
inventory.

## How to read this package

- Everything here is **derived from files already in the repo** — the
  canonical journey manifest, the migration/dependency-closure JSON reports,
  the acceptance checklist, and the visual-proof contact sheets. Where a
  document restates a fact from one of those, the source file is named so it
  can be re-verified directly rather than taken on faith.
- Nothing in this package was re-tested from scratch for this handoff pass —
  it consolidates and cross-references existing, already-verified artifacts
  from the same integration branch. Doc 07 states exactly which checks are
  current and which are the same ones already reported earlier in this
  branch's history.
- **This package does not authorize merge, deploy, or "owner approved"
  status.** Every document in it repeats the same explicit non-status found
  in `docs/smokecraft/integration/MAIN_INTEGRATION_ACCEPTANCE_CHECKLIST.md`:
  not merged, not deployed, not owner-approved. That determination belongs
  solely to the repository owner.
